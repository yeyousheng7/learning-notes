## 如何使用本站

- 使用顶部导航切换笔记分类。
- 使用页面右侧目录快速定位章节。
- 点击代码块右上角的复制按钮，一键复制完整提示词。
- 点击页面右上角的主题按钮，切换浅色或深色模式。

!!! tip "阅读建议"
    提示词不必原样照搬。先选择最接近目标的模板，再补充课程名称、学习进度、考试题型等上下文，效果通常会更好。
