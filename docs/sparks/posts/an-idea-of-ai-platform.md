# 关于 AI 平台的一点思考

最近看到周边人有在做 AI 平台，它们会注重生成 PPT 的能力，生成图片的能力，生成文案的能力。这些当然没有错，AI 能力很重要。但是，我认为作为一个平台，内容才是更重要的。

换句话说，**内容第一，AI 能力第二。AI 应该是锦上添花，而非平台的全部。** 这里的内容并不只是狭义的数据，也包括平台自身提供的资源、服务、功能与生态。一个平台如果除去 AI，便没有自己的特色了，那么很容易被平替。

举个例子，Code Agent。现在 Code Agent 已经很多了，但比较出名的，又有几个是纯靠 Agent 本身的？OpenCode、Cursor，除了 Agent 能力，用户还会看套餐、额度，以及平台本身提供的体验。而像 Pi 这样的 Agent，从工程实现上来说，现在类似的项目已经遍地都是，效果不错的也有那么一些。仅仅做出一个好的 Agent，似乎已经越来越难形成独特的竞争力。

或许有人会问，OpenAI 这类公司不就是纯 AI 吗？但需要注意，这些巨头是大模型公司，它们提供的内容就是模型本身。这与我所讨论的 AI 平台并不是一回事。

无论是 AI4Science、AI4Teach，还是什么其他领域的 AI 平台，重点都应该放在其所服务的领域上。**AI4Science 的重点是 Science，AI4Education 的重点是 Education**，AI 是辅助，不是全部。

平台需要有自己的内容，并将平台技术与内容深度结合，形成真正有价值的服务。AI 可以进一步提升这些内容的价值，但不能代替内容本身。

归根结底，**AI 是一种技术手段，而不是平台价值的全部。** 一个 AI 平台真正需要回答的，不只是它的 AI 能做什么，更是这个平台本身究竟能够为用户提供什么。
