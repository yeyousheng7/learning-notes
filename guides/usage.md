# 使用说明

本项目包含普通笔记与“灵光”随想。灵光按时间线展示，支持公开和加密文章。

以下命令均在项目根目录执行。

## 环境准备

本项目使用 [uv](https://docs.astral.sh/uv/) 管理 Python 环境与依赖。安装 uv 后，执行：

```powershell
uv sync
```

## 普通笔记

普通笔记保存在 `docs/` 下对应的分类目录中。修改已有文章可直接编辑 Markdown；新增文章后，在 `mkdocs.yml` 的 `nav` 中添加入口，需要时同步更新首页链接。图片等资源放在对应文章的资源目录，并使用相对路径引用。

## 灵光（公开）

公开的随想文章直接在 `docs/sparks/posts/` 下新建 Markdown，无需修改导航，文章会自动出现在“灵光”时间线中：

```markdown
---
date: 2026-11-15
slug: a-new-thought
---

# 一些随想

这里写正文。
```

`slug` 决定文章网址，每篇需要保持唯一。可添加 `draft: true` 暂缓发布，本地预览仍可查看。

### 列表摘要

摘要有两种方式，使用 `<!-- more -->` 时优先按标签截断：

- **手动截断**：标签之前的内容作为摘要，不受 60 字符限制，也不额外添加省略号。
- **自动截断**：没有标签时，正文不超过 60 字符就完整展示，超过则取正文纯文本的前 60 字符。中文、英文字母和标点都按字符计数，标题不计入。

自动截断后，末尾是中英文句号、问号、感叹号（`。！？.!?`）或已有省略号时，不再补省略号；其他情况添加 `...`，并去掉末尾的逗号、顿号、分号、冒号或破折号等未完句标点。末尾有引号或括号时，先看它前面的标点。

例如，手动指定摘要可以这样写：

```markdown
这一段会出现在列表中。

<!-- more -->

这一段只在打开文章后显示。
```

以上规则只控制列表摘要，文章页始终显示全文。

## 灵光（私密加密）

原文放在 `local/sparks/`，脚本将加密版本生成到 `docs/sparks/posts/private-随机编号.md`。整个 `/local/` 已被 Git 忽略，原文和密码请自行备份，不要放进 `docs/` 或强行加入 Git。

### 首次配置

```powershell
uv run python -m scripts.sparks init
```

编辑 `local/sparks.toml`，填写所有私密文章共用的密码，保留工具生成的 `salt`：

```toml
password = '在这里设置一个独立的长密码'
```

密码可以包含中文；使用上述单引号写法时，不要包含单引号或换行。

### 写文章

```powershell
uv run python -m scripts.sparks new "一些随想"
```

随后编辑 `local/sparks/一些随想.md`：

```markdown
---
id: 工具生成的32位随机编号
date: 2026-11-15
encrypted: true
public_title: 一些随想
---

这里正常写正文，可以使用 Markdown 的段落、列表、强调和代码等排版。
```

保持 `id` 不变，本地文件可以改名。`public_title`、日期、随机编号网址和加密状态会公开；私密标题可写进正文。也支持 `draft: true`。

目前只支持文字和 Markdown 排版，不支持图片、嵌入媒体或脚本。

加密文章不使用上述摘要规则：列表只显示公开标题、日期、锁图标和“内容已加密”，也不参与全文搜索。原文中的 `<!-- more -->` 不会公开标签前的内容，也不会截断正文；打开文章并解锁后显示全文。解锁后，列表仍不展示正文摘要。目前不支持单独设置公开摘要。

### 生成加密版本

修改原文后运行：

```powershell
uv run python -m scripts.sparks prepare
```

脚本读取本地密码生成密文，内容未变时保留已有版本。只需维护原文，不要手工修改生成文件；普通 Git 提交不会自动执行 `prepare`。

修改密码后，也要重新运行 `prepare`，并将全部生成文件一起发布，因此需要保留所有原文。已保存的旧密文仍可用旧密码解密。

若提示发布文件没有对应原文，先确认原文是否齐全。确实要删除这些文章时，执行：

```powershell
uv run python -m scripts.sparks prepare --prune
```

此命令只清理没有对应原文的加密生成文件，删除结果随下次提交发布。

## 本地预览

**常规预览**：查看公开文章与已生成的加密文章，也可测试密码解锁。

```powershell
uv run mkdocs serve
```

**私密原文预览**：直接查看明文，无需密码或提前生成密文，页面会标注“本地私密原文预览”。

```powershell
uv run python -m scripts.sparks preview
```

默认访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)，保存文件后自动刷新，按 `Ctrl+C` 停止。常规预览要先运行 `prepare`，才能看到私密原文的更新。

原文预览只监听本机，端口被占用时可添加 `--port 8001`。临时 Markdown 放在 `local/` 下，预览网页放在系统临时目录，正常退出后清理，不写入项目的 `docs/` 或 `site/`。不要公开预览服务或上传临时目录。

## 构建与发布

准备好文章及加密版本后，检查正式构建和修改内容：

```powershell
uv run mkdocs build --strict
git diff
```

确认修改后，正常暂存、提交并推送。推送到 `main` 分支后，GitHub Actions 会自动构建并部署网站。构建结果位于 `site/`，该目录无需提交。

## 线上阅读与安全说明

输入密码解锁后，同一标签页中刷新或打开其他加密文章会自动解锁。网站仅临时保存派生密钥，不保存原始密码；点击“锁定”会清除密钥并隐藏正文。关闭标签页通常会结束会话，但浏览器恢复或复制标签页时可能保留，离开前可主动锁定。

线上解锁需要 HTTPS（GitHub Pages 已支持），本机预览地址也可使用。浏览器禁用会话存储时，需要逐页解锁。

密文可被公开下载，请使用独立的长密码。加密不能防止他人查看已解锁的页面，也无法抵御恶意扩展或被篡改的网页。忘记密码后可用本地原文重新生成；只剩密文时无法找回密码。
